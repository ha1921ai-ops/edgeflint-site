# EdgeFlint Site

موقع ثابت وخفيف يعمل مباشرة على GitHub Pages من دون نظام بناء أو إطار برمجي.

## بنية الموقع

- `index.html`: الصفحة العربية لخدمات تصميم المواقع.
- `site.css`: هوية صفحة الخدمات، الألوان، المقاسات، وتصميم الهاتف.
- `site.js`: قائمة الهاتف وتنبيه زر WhatsApp في نسخة المعاينة.
- `domains/index.html`: واجهة بيع الدومينات باللغة الإنجليزية.
- `styles.css` و`script.js`: تصميم الدومينات وقائمة الأسماء والأسعار.
- مجلدات مثل `bookwormdreams/`: صفحات الدومينات الفردية. يجب إبقاء مساراتها كما هي.
- `assets/`: الشعار وصور المشاريع.

## التعديل السريع

- نصوص وأقسام الصفحة الرئيسية: عدّل `index.html`.
- الألوان الأساسية: عدّل المتغيرات الموجودة في بداية `site.css`.
- إضافة أو حذف دومين وتغيير سعره: عدّل مصفوفة `domains` في `script.js`.
- ربط WhatsApp: استبدل زر `data-preview-whatsapp` في `index.html` برابط `wa.me` ثم احذف رسالة المعاينة المرتبطة به.

## المعاينة محلياً

من داخل مجلد المشروع شغّل:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

فرع `main` هو الموقع الحي. يجب مراجعة فرع المعاينة والموافقة عليه قبل دمجه في `main`.
